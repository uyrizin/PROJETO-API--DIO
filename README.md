# Projeto API DIO em C#

Este projeto foi desenvolvido como parte dos cursos da **Digital Innovation One (DIO)**.  
O objetivo é criar uma API em **C#** utilizando **.NET** para praticar conceitos de desenvolvimento backend.

## 🚀 Tecnologias utilizadas
- C#
- .NET 6/7
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server (ou outro banco configurado)
- Swagger para documentação
